# AI-Based Cotton Disease Detection using MobileNetV2

## Overview

This project presents a deep learning based cotton disease detection system using MobileNetV2, Transfer Learning, Explainable AI (Grad-CAM), Severity Estimation and Treatment Recommendation.

## Features

- Multi-Class Cotton Disease Classification
- MobileNetV2 Transfer Learning
- Fine-Tuning
- LeakyReLU and Swish Activation
- Grad-CAM Explainable AI
- Severity Estimation
- Treatment Recommendation

## Technologies

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib
